# Kanis Lupus — Founding Circle Portal

A private member portal for the Kanis Lupus founding circle. Built for serious readers who want direct access to the work before anyone else.

## What this is

A self-contained HTML portal for the **$50/month founding circle** — no external platform, no algorithm, fully under the Kanis Lupus brand.

## Features

- **The Work** — a scheduled content feed with filters by type (research, poems, chapters, novels, scripts, live sessions, process vlogs)
- **Live chat** — a real-time community space for founding members
- **Direct file upload** — upload video, audio, and images directly, no links needed
- **Auto-publishing** — posts go live on their scheduled date automatically
- **Admin panel** — schedule posts, upload media, manage everything from one place

## Files

| File | Purpose |

| `index.html` | Landing page — public facing |
